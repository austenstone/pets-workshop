Run Python and browser tests in parallel

Outcome: every push and pull request runs API unit tests and Playwright end-to-end tests.

Create .github/workflows/run-tests.yml with two independent jobs:

  • Install dependencies with pip and npm ci.
  • Let both jobs run simultaneously by leaving out needs.

6 12 minutes Facilitator demo

Deploy to Azure after CI passes

Outcome: understand a passwordless, CI-gated deployment without needing an Azure subscription.

Observe a prepared repository as a successful test run triggers deployment of the exact commit that passed CI.

  • workflow_run gates deployment on the completed CI workflow.
  • head_sha identifies the validated commit.
  • OIDC provides short-lived Azure authentication without a stored password.
  • Concurrency prevents conflicting production deployments.
  • Bicep defines the application infrastructure as code.

Do not run Azure commands during the workshop. The successful workflow and deployed application are prepared in advance.

Turn CI into an enforced repository rule

Outcome: see a pull request blocked until one stable summary check passes.

The prepared repository adds a tests-passed summary job, then requires that check through a ruleset targeting the default branch.

  1. Require changes through pull requests.
  2. Require the tests-passed status check.
  3. Keep required approvals at zero for a solo repository.
  4. Observe the merge button unlock only after CI succeeds.
